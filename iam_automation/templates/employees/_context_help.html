Employee workspace

How to use this page

This profile is source-owned.SRS, AccessNow and Master Roster Lock values are shown together, but one source does not overwrite another.

Use the profile tree to move from the canonical employee to each source platform. Expand a source to see its identifiers, snapshots and complete source fields.

The overview is read-only so you can compare platforms safely.

  • SRS: supplier and Fieldglass worker details.
  • AccessNow: active/termination status and AccessNow identifiers.
  • Master Roster Lock: roster and vendor engagement values.
  • When values disagree, compare the source, file and observed timestamp before changing anything.

Use Review source updates for incoming files. Compare current and incoming values field by field, then select only the fields that should be applied.

Use Edit profile only for an administrative change. The Business reason is required and the change goes through approval; it is not saved directly.

History is created when a change is applied locally. Publishing SQLite only shares that local history with other workstations.

If another workstation cannot see a change, verify that the database was published and that the workstation refreshed its workspace.
