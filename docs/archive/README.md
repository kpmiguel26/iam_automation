# Documentation Archive

This folder contains historical material that is retained for traceability but
is not the active project baseline. Archived documents must not be used as the
current requirement, architecture or delivery status without checking
[`../STATUS.md`](../STATUS.md) and the active documentation hub.

## Archive groups

| Folder | Contents | Current replacement |
|---|---|---|
| `legacy-numbered-design/` | Original numbered POC/design series and old test/debt snapshots | [Current architecture](../../ARCHITECTURE.md), [ADRs](../../adr/), [status](../STATUS.md) |
| `rejected-architecture/` | Centralized coordinator architecture rejected by the project | [Current architecture](../../ARCHITECTURE.md) |
| `meetings/` | July meeting notes, touchpoint files and source workbooks | [Current meetings](../../meetings/), [UAT decisions](../../uat/UAT_NEXT_MEETING_DECISIONS.md) |
| `work-tracking/2026-07/` | July work sessions and daily closure records | [Current work tracking](../../work_tracking/README.md), [status](../STATUS.md) |
| `presentations/` | Historical architecture presentation and generated deck | [Architecture docs](../../architecture/) |
| `requirements/` | WFM requirements workbook retained for future planning | [IAM requirements](../../req/IAM%20Automation%20Software%20Requirements%20Tracker.xlsx) |
| `legacy-artifacts/` | Unclassified historical onboarding artifact | [Documentation hub](../README.md) |

## Archive rules

- Archive by moving, never deleting, unless separately authorized.
- Preserve original filenames and add a mapping here when a document has a
  current replacement.
- Do not link archived material from active plans as if it were current.
- Historical meeting and evidence files are retained for audit/context even
  when their decisions have been superseded.
- Historical work-tracking documents may retain their original status text as
  a snapshot; that text is not the current project status.
