# Architecture Decision Record

## Context

IAM Automation must work inside current constraints: Access database, SharePoint document library, and OneDrive sync.

## Decision pending

The POC will decide between:

- Direct Access usage.
- Local working copy with controlled publication.
- Single-writer workstation or service.
- Future migration to a real database engine.

## Decision gates

No full IAM application should be implemented until the POC answers the decision gates in the project brief.
