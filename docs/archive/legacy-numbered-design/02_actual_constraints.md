# Actual Constraints

Unavailable infrastructure:

- Dedicated Windows server, VM, VDI, central API, or Windows Service host.
- SQL Server, PostgreSQL, MySQL, managed cloud database, or dedicated database engine.
- Continuously running coordinator process.
- Reliable shared transactional file server.

Available infrastructure:

- Windows workstations.
- Separate installed app copy per user.
- Microsoft Access `.accdb`.
- SharePoint document libraries and OneDrive synchronization.
- Excel, Python, Windows identity, and local workspaces.

Python 3.10 compatibility is required.
