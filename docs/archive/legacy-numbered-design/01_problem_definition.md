# Problem Definition

IAM Automation centralizes employee and user data and generates provisioning templates for SAP Fieldglass, Salesforce, NICE IEX, and future systems.

The application is installed separately on multiple Windows workstations. It must validate users, collect proposed changes, support approvals, maintain auditability, and publish controlled Access snapshots.

The full UI should not be built before the POC proves request submission, administrator batch processing, Access connectivity, versioning, audit, recovery, and Excel generation.
