Rules Engine

Rules were also organized by execution phase: before rules evaluated a pre-flight, normalized file before ingestion, while after rules ran against the ingested data in the database to support searches, controls, and alerts on stored information
- Miguel explained that rule creation included the creation rule, execution phase, report source, fields, operator, value, right operand, severity, rule name, and description. - Miguel explained that the application currently supported one calculated value, “business days between,” for evaluating the 30-day rehire rule. The rule first checked whether the access status was terminated or deactivated; matching records were activated as true and sent for review in quarantine
