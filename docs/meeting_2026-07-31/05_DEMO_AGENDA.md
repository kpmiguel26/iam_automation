# Demo Agenda

## Suggested 20-minute walkthrough

### 1. Startup and identity - 3 minutes

- Launch the desktop preflight.
- Select or confirm the local SharePoint/OneDrive folder.
- Show Access and SQLite validation.
- Explain that Windows identity is recorded for traceability and application login is separate.

### 2. Application access - 2 minutes

- Sign in with an application account.
- Show the role-aware command bar and notification counter.
- Explain the separation between Application Admin and Master Admin.

### 3. Shared request and approval - 4 minutes

- Create or open a request.
- Show the complete payload and business reason.
- Assign a reviewer.
- Approve or reject with a decision note.
- Show the audit event and publication notification.

### 4. Roster Lock ingestion - 4 minutes

- Place an approved sample workbook in the synchronized source folder.
- Show the watcher detecting the file.
- Show the import batch, valid rows and quarantine rows.
- Show staged worker candidates and the matching status.

### 5. RSR enrichment - 3 minutes

- Show RSR Supplier Worker Details as a separate source.
- Explain vendor derivation from the Statement of Work.
- Show matched, unmatched and discrepancy outcomes.

### 6. Employee directory - 2 minutes

- Search by name or identifier.
- Filter by vendor, source, status and engagement.
- Open the profile and show engagements, identifiers, lineage and discrepancies.

### 7. Governance and recovery - 2 minutes

- Show notifications and audit history.
- Show database publication status, checksum and backup.
- Explain that Access publication is explicit and controlled.

## QA handoff message

Please report whether each demonstrated workflow is:

- working as expected;
- partially working with a usability issue;
- blocked by a missing requirement or source field; or
- failing with a reproducible error.

Each report should include the screen, action, expected result, actual result, timestamp, user role and source file used.
